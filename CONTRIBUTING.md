# Contributing

Contributions should improve factual accuracy, evidence coverage or reproducibility.

## Corrections

Provide:

1. the record ID;
2. the exact claim at issue;
3. the proposed correction;
4. a reliable public source; and
5. the relevant source date.

Do not submit personal contact data, confidential deal information, licensed database exports or unsupported deal-team attribution.

## New records

New entities need a stable ID, official name, category, inclusion basis, at least one canonical source and a verification date. New relationships require a source that supports both endpoints and the relationship type.

Run `npm run check` before opening a pull request.
